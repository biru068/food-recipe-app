# 🍔 FoodApp

A modern and responsive Food Recipe application built with **React.js** and **Vite**. Users can search for recipes, view detailed ingredients and cooking instructions, browse menu items, and navigate through multiple pages using React Router.

## 🚀 Features

- 🔍 Search food recipes
- 🍕 View recipe details
- 🥗 Display ingredients
- ⏱️ Cooking time and servings
- 📋 Menu page
- 📖 Recipes page
- ℹ️ About page
- 📞 Contact page
- 📱 Responsive design
- ⚡ Fast performance with Vite

## 🛠️ Technologies Used

- React.js
- Vite
- React Router DOM
- JavaScript (ES6+)
- CSS Modules
- HTML5
- Spoonacular API

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/food-recipe-app.git
```

Go to the project folder:

```bash
cd food-recipe-app
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## 🌐 API

This project uses the **Spoonacular API** to fetch recipe data.
